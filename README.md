# 🎟️ Eventra – Event Management Platform

## 📌 Project Overview

Eventra is a modern and responsive event management platform designed to help users discover, explore, and book events easily.

The platform provides a simple and user-friendly experience for finding concerts, tech events, workshops, sports, festivals, and other experiences. Users can browse events, search and filter by category, view event details, select tickets, and complete the booking flow.

## 🚀 Key Features

* Welcome screen with Eventra introduction
* Login and Google login interface
* Event discovery and search
* Browse events by categories
* Featured and upcoming events
* Event details page
* Favorite events functionality
* Ticket selection and quantity controls
* Booking progress flow
* Order summary and payment interface
* Booking confirmation screen
* Digital ticket with QR code
* User dashboard
* My Tickets and booking history
* Responsive navigation
* Mobile-friendly bottom navigation
* Responsive design for desktop, tablet, and mobile

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* CSS Flexbox
* CSS Grid
* Responsive Web Design
